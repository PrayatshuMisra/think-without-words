# Think Without Words — Design Direction

## Three approaches

### Theme Name: Field Notes / Editorial Lab
Very Brief Intro: A warm paper-toned research interface that combines scientific notation, editorial typography, and tactile instrument panels. The experience feels like an annotated lab notebook made interactive.
Probability: 0.07

### Theme Name: Signal / Minimal Instrument
Very Brief Intro: A restrained black-and-white instrument panel with one precise signal color, dense measurement marks, and highly reduced geometry. The emotional intent is focus, rigor, and controlled experimentation.
Probability: 0.04

### Theme Name: Quiet Atlas / Systems Map
Very Brief Intro: A pale cartographic interface where latent states appear as paths through a conceptual landscape. The tone is calm, exploratory, and spatial without using decorative sci-fi tropes.
Probability: 0.08

## Chosen Direction: Field Notes / Editorial Lab

### Design Movement
Swiss editorial design translated into a contemporary scientific field notebook: asymmetrical composition, visible structure, typographic hierarchy, and diagrams that explain rather than decorate.

### Core Principles
1. Every visual element must clarify the central claim: hidden state updates can perform useful computation without emitting a verbal trace.
2. The interface should feel observed and measured, not gamified or mystical.
3. Contrast comes from near-black ink, mineral paper, and one ownable signal color rather than gradients or neon.
4. Interaction is an invitation to inspect a mechanism: controls expose trade-offs and honest uncertainty.

### Color Philosophy
Use a warm mineral paper background (#F3F0E8) as the laboratory surface, near-black ink (#191A18) for authority, graphite borders (#B8B4AA) for structure, and a restrained burnt-copper signal (#C45A3A) for active computation, transitions, and truth-state markers. Copper signals change without feeling like a generic success green or technology blue.

### Layout Paradigm
Use a measured asymmetric editorial canvas: wide left columns for explanation, narrow annotation rails for metadata, and instrument panels that break the page rhythm. Avoid centered hero-only layouts; let diagrams and labels create a visible research apparatus.

### Signature Elements
- Small monospace lab labels with section numbers and status markers.
- Copper state traces that move through compact matrix blocks and activation bars.
- Fine ruled dividers, offset annotation cards, and a subtle dot-grid field behind the hero visualization.

### Interaction Philosophy
Controls should behave like laboratory instruments. Changing inference steps updates the state sequence, estimated latency, confidence, and output immediately. The interface always pairs model output with ground truth and labels toy simulation values honestly.

### Animation
Motion should be precise and short: state bars morph with a 220ms ease-out; copper traces pulse only while computation is active; section reveals use a 40ms stagger; no decorative parallax. Respect reduced-motion preferences by switching to instant state changes while preserving semantic differences.

### Typography System
Display: Space Grotesk, 600–700, for large editorial headings and research claims. Body: IBM Plex Sans, 400–500, for explanatory copy. Technical: IBM Plex Mono, 400–600, for labels, metrics, task values, and state identifiers. Headings use tight tracking; technical labels use uppercase with generous letter spacing.

### Brand Essence
An interactive field guide to hidden computation for technically curious learners — distinct because it makes latent reasoning inspectable without pretending the hidden state is readable prose.
Personality: rigorous, curious, candid.

### Brand Voice
Headlines are direct questions or crisp claims. CTAs are invitations to test a mechanism, never hype. Microcopy states what is known, simulated, and still open.

Example lines:
- “More steps. Less trace. Watch what changes.”
- “The answer is visible. The path is not.”

### Wordmark & Logo
A compact wordmark set in Space Grotesk with the “O” in WORDS replaced by a copper ring enclosing three offset state bars. The standalone mark is a square copper bracket containing three horizontal bars, one of which shifts position to imply recurrent updating.

### Signature Brand Color
Burnt Copper — #C45A3A.

## Style Decisions
- Keep the page light, paper-toned, and editorial; no generic AI gradients, robot imagery, or glassmorphism.
- Make the experiment the visual center of gravity and ensure every metric has an honest toy-simulation label.
- Use diagrams, fine borders, and typography for visual interest rather than decorative illustration.
